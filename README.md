# IICS Technical Assessment — 12 Versions

Static GitHub Pages site. Versions: **Open-ended 1–6** and **Multiple-choice 1–6**, 20 questions each
(8 Beginner, 8 Moderate, 2 Advanced, 2 Expert). No answer key or grading is included.

On submit, the candidate's responses are downloaded as `.txt` and `.json` files, which they send to the assessor.
Nothing is sent to a server; refreshing before submitting loses answers.

## Deploy on GitHub Pages
Upload `index.html`, `styles.css`, `app.js`, `README.md` to a repo, then Settings → Pages → Deploy from branch → `main` / root.

## Run locally
Open `index.html` in a browser.
